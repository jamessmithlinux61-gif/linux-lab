## Component Inventory

Detailed component identification is pending as part of the `INC-002` investigation.

The following components will be recorded during physical inspection:

* Motherboard manufacturer, model, and revision
* CPU model
* Memory module count, capacity, and specifications
* Power-supply manufacturer, model, wattage, and approximate age
* Storage-device models and health information
* Graphics hardware
* Network adapters
* Expansion cards and other relevant internal hardware

## Notes

Carrier is a custom-built system and therefore has no single OEM system model or system-level serial number that can be used as a complete hardware reference.
