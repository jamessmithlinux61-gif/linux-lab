# Linux-Lab
Welcome to my Linux and system administration learning journal

This repository documents my progress as I work toward becoming a Linux System Administrator. It includes hardware upgrades, operating system installations, networking labs, Bash scripting, Python projects, troubleshooting notes, and lessons learned.
## Hardware
### Laptop
- Acer Aspire 5
- Windows 11 (host operating system)
- VirtualBox for Linux virtual machines
### RAM Upgrade (Successful)
#### Original configuration
- 4 GB DDR4
#### Upgrade
- Added 8 GB DDR4-2666 SODIMM
- Total memory now 12 GB
**Result** The upgrade completed successfully and significantly improved the laptop's responsiveness, especially when running VirtualBox and multiple applications simultaneously.
#### Storage Upgrade Attempt (Unsuccessful)
Drive purchased 
- PNY CS900 500 GB SATA SSD
**Objective** Install a dedicated SSD for Linux virtual machines and lab work.
**Result** The SSD could not be installed because the laptop lacked the required SATA cable/connector arrangement, resulting in misalignment and improper fit into the designate space.
**Lesson learned** *Never* assume that an empty drive bay includes the required cabling and/or connector. Verify all internal hardware for cable/connector requirements and physical space requirements, before purchasing upgrade components.
